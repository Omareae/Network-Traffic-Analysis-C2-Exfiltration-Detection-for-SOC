## 📌 Project Overview

This project focuses on analyzing network traffic to identify suspicious activities, detect potential Command and Control (C2) communication, and investigate possible data exfiltration from a SOC analyst's perspective.

The project is divided into four practical weeks, covering network traffic fundamentals, protocol analysis, threat detection, and AI-assisted investigation.

## 🎯 Project Objectives

- Understand network protocols and communication behavior.
- Capture and analyze network traffic using Wireshark.
- Identify suspicious connections and network anomalies.
- Investigate potential C2 beaconing and data exfiltration.
- Analyze network logs and security alerts using Zeek and Suricata.
- Detect reconnaissance and service enumeration activities.
- Map suspicious activities to the MITRE ATT&CK framework.
- Use local AI models to assist with network traffic investigation and reporting.

## 🔍 Project Scope

The project covers the following technical areas:

- **Network Traffic Analysis:** Capturing and inspecting network communications and protocols.
- **Protocol Analysis:** Investigating HTTP, DNS, SMB, TLS, and TCP traffic.
- **Threat Detection:** Identifying suspicious network behavior, reconnaissance, and potential attacks.
- **C2 Detection:** Investigating beaconing patterns and suspicious command-and-control communications.
- **Data Exfiltration Detection:** Identifying unusual outbound traffic and potential data transfer activities.
- **Network Security Monitoring:** Analyzing network logs and alerts using Zeek and Suricata.
- **MITRE ATT&CK Mapping:** Correlating observed activities with relevant adversary techniques.
- **AI-Assisted Investigation:** Using local LLMs to support traffic analysis and investigation reporting.
